# Calistenia con Salud — Calistenia con Dolor

Landing page del programa "Calistenia con Dolor", con el semáforo del dolor (autoevaluación) y una guía de qué hacer según el resultado.

## Estructura

- `index.html` — página principal.
- `semaforo.html` — test de autoevaluación "El semáforo del dolor".
- `que-hacer.html` — guía de referencia: qué hacer según el color del resultado.
- `assets/` — imágenes originales (logo, foto) usadas para generar los HTML.

## Uso

Los tres archivos HTML están enlazados entre sí con rutas relativas, así que deben mantenerse juntos en la misma carpeta (o subirse juntos a la raíz de un hosting) para que los enlaces funcionen correctamente. Al abrir `index.html`, no necesitas ningún servidor: funciona como archivo estático.
